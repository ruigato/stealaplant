# Event System Design

## Overview

**Steal a Plant** features weekly community events that combine gameplay with YouTube community engagement. Events are designed to be fun, chaotic, and memorable experiences that build player loyalty and community.

## Event Schedule

### Weekly Events
- **Day**: Every Saturday
- **Time**: 18:00 (6:00 PM) Portugal Time (WET/WEST)
- **Duration**: 30-40 minutes
- **Frequency**: Once per week
- **Style**: Admin Abuse events

### Time Zone Reference
Portugal times (for international players):
- **Portugal**: 18:00 WET (Winter) / WEST (Summer)
- **UK**: 18:00 GMT / 19:00 BST
- **US East**: 13:00/14:00 EST/EDT
- **US West**: 10:00/11:00 PST/PDT

## Event Type: Admin Abuse

### Concept
"Admin Abuse" events are controlled chaos where admins:
- Spawn rare/impossible plants
- Modify game parameters in real-time
- Create unexpected scenarios
- Interact directly with players
- Make the game temporarily "broken" in fun ways

### Example Activities
- Spawn 100 Rainbow Divine plants at once
- Make the conveyor belt super fast
- Give random players huge amounts of money
- Spawn giant versions of plants
- Reverse the conveyor belt direction
- Make plants fly instead of fall
- Temporarily add impossible plant variants
- Random teleportation of players
- Instant base expansions
- Money fountains

### Event Goals
- **Entertainment**: Create memorable, shareable moments
- **Community Building**: Players want to attend and participate
- **Content Creation**: Exciting footage for YouTube
- **Rewards**: Give participants special items/plants/money
- **Marketing**: Events drive YouTube views and new players

## YouTube Integration

### Channel Purpose
The Steal a Plant YouTube channel serves as:
- Event announcement platform
- Gameplay showcase
- Highlight reel from events
- Community engagement hub
- Marketing and growth tool

### Weekly Cycle
1. **Monday-Friday**: Upload gameplay videos, teasers, announcements
2. **Throughout Week**: Community comments with Roblox usernames
3. **Friday**: Announce Saturday event details
4. **Friday Evening**: Draw the weekly winner
5. **Saturday 18:00**: Host live event with winner
6. **Sunday-Monday**: Upload event highlights

## Giveaway System

### How to Enter
1. **Watch** Steal a Plant videos on YouTube
2. **Comment** your Roblox username on the video
3. **One comment = One entry** (commenting multiple times doesn't increase chances)
4. **Must have a valid Roblox account**

### Winner Selection
- **Timing**: Drawn before each Saturday event (e.g., Friday evening)
- **Method**: Random selection from valid comments
- **Announcement**: Posted in YouTube community tab and video announcement
- **Notification**: Winner contacted via YouTube comment reply

### Winner Prize
The selected winner receives:
- **Friend request** from the admin Roblox account
- **Invitation** to the private admin server for the event
- **VIP status** during the event
- **Special attention** from admins during chaos
- **Exclusive rewards** (extra rare plants, money, items)
- **Screen time** in event highlight video

## Admin Server

### Server Structure
- **Private Server**: Separate from public servers
- **Capacity**: TBD (admins + winner + special guests?)
- **Duration**: Event time only (30-40 minutes)
- **Access**: Invite-only

### Participants
- **Admin Team**: Joaquim and classmates/team members
- **Weekly Winner**: The selected YouTube participant
- **Special Guests** (optional): Previous winners, VIPs, helpers

### Event Flow
1. **0:00 - Pre-Event** (5 min)
   - Winner joins server
   - Admins welcome and explain
   - Set up starting positions

2. **0:05 - Warm-up** (5 min)
   - Normal gameplay
   - Admins chat with winner
   - Build anticipation

3. **0:10 - Chaos Begins** (20-25 min)
   - Admin abuse activities
   - Random rewards
   - Unexpected events
   - Maximum fun

4. **0:30 - Grand Finale** (5 min)
   - Final big reward for winner
   - Screenshot opportunities
   - Thank yous and goodbyes

5. **0:35-0:40 - Wrap-up**
   - Winner receives final prizes
   - Admins thank everyone
   - Event ends

## Content Creation Strategy

### Video Types

#### 1. Event Highlights
- **Content**: Best moments from Saturday events
- **Length**: 8-15 minutes
- **Upload**: Sunday/Monday after event
- **Purpose**: Showcase fun, encourage entries

#### 2. Gameplay Videos
- **Content**: Regular gameplay, tips, showcases
- **Length**: 5-10 minutes
- **Upload**: 2-3x per week
- **Purpose**: Maintain engagement between events

#### 3. Event Announcements
- **Content**: This week's event theme, giveaway reminder
- **Length**: 1-3 minutes
- **Upload**: Friday before event
- **Purpose**: Drive entries and attendance

#### 4. Winner Announcements
- **Content**: Revealing the weekly winner
- **Length**: 1-2 minutes (can be YouTube Short)
- **Upload**: Friday evening
- **Purpose**: Build hype for Saturday

### Content Goals
- Build subscriber base
- Encourage comments (entries)
- Showcase game features
- Create FOMO (Fear of Missing Out)
- Generate shareable moments

## Community Guidelines

### Fair Play
- One entry per person per week
- Must use real Roblox username
- No alternate accounts for extra entries
- Admins reserve right to disqualify suspicious entries

### Behavior Expectations
- Event winners must be respectful
- No begging for extra rewards
- Follow Roblox ToS during events
- Represent the community positively

### Safety
- No sharing personal information
- Parent permission required for minors
- Record events for safety/moderation
- Admins can remove disruptive participants

## Marketing Benefits

### Growth Strategy
Events drive:
- **YouTube subscribers** (need to subscribe to see announcements)
- **Video views** (checking for winners, watching highlights)
- **Comments** (everyone entering giveaway)
- **Roblox plays** (players want to practice for events)
- **Word of mouth** (players tell friends about fun events)

### Viral Potential
- Crazy moments are shareable
- Winners will tell their friends
- Unique Portuguese origin story
- "Admin Abuse" is entertaining content
- Community-driven participation

## Success Metrics

Track to measure event success:
- YouTube subscribers gained
- Comments per video (entries)
- Event attendance
- Video views on event highlights
- New Roblox players after events
- Community engagement (likes, shares)
- Player retention (returning players)
