# Steal a Plant 🌱

A Roblox game inspired by Steal a Brainrot, but with plants!

## Project Overview

**Steal a Plant** is a plant collection and trading game where players can:
- Collect plants of various rarities
- Discover mutations
- Trade with other players
- Participate in weekly admin events
- Build their plant collection in their index

## Quick Info

- **Language**: English
- **Origin Country**: Portugal
- **Target Audience**: Kids and teens who love collecting games
- **Platform**: Roblox
